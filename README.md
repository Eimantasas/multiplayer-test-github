# Simple 3D Multiplayer Tag Game (Godot)

A very simple 3D multiplayer tag game built with [Godot Engine](https://godotengine.org/) (v4.x). Players must shoot a target to get points. Target respawns after being shot. Designed for learning basic networking using RPC in Godot.

---

## 🎮 Features

- Basic 3D movement
- Multiplayer support via Godot's high-level networking (RPC)
- Simple shoot mechanic
- Minimal 3D environment (rectangles, planes)

---
